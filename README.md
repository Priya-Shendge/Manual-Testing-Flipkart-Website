# Manual Testing – Flipkart Website (Sample QA Project)

## Overview
This repository contains a sample **manual QA testing project** performed on the
public [Flipkart](https://www.flipkart.com) e-commerce website. It demonstrates
the end-to-end manual testing process a QA fresher/tester follows — from
test planning to test case design, execution, and bug reporting.

> This is an independent learning/portfolio project created for practicing and
> showcasing manual testing skills. It is not affiliated with or endorsed by
> Flipkart.

## Objective
To validate core functional flows of the Flipkart website (search, product
browsing, cart, wishlist, login/signup UI, and checkout flow up to payment
selection) and document the testing process the way it is done in a real QA
role.

## Scope
**In scope:**
- User Registration / Login (UI-level validation)
- Product Search & Filters
- Product Listing & Product Details Page
- Add to Cart / Update Cart / Remove from Cart
- Wishlist
- Checkout flow (Address → Order Summary → Payment options screen)

**Out of scope:**
- Actual payment transactions (no real payment is made/tested)
- Backend / API / database testing
- Performance and security testing

## Testing Type
Manual, Black-box, Functional & UI Testing

## Tools Used
- Browser DevTools (for basic UI/console checks)
- Excel / Google Sheets (test case & bug documentation)
- Flipkart website (www.flipkart.com) as the System Under Test (SUT)

## Repository Contents
| File | Description |
|---|---|
| `Test_Plan.md` | Testing scope, approach, environment, and entry/exit criteria |
| `Test_Cases.xlsx` | Detailed test cases with steps, expected results, and status |
| `Bug_Report.xlsx` | Sample bugs/observations logged during execution |
| `Test_Summary_Report.md` | Final summary of test execution and results |
